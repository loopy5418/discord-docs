# Getting started

These pages take you from nothing to a running bot.

1. [Installation](installation.md): install Sonata, create a project and add `discord` to it.
2. [Setting up a Discord application](discord-application.md): create the application, get a token, choose intents and invite the bot.
3. [Your first bot](first-bot.md): write a bot with a slash command, a prefix command and a button, and run it.
4. [Project structure](project-structure.md): split a growing bot into folders of commands, components and events.
5. [Building a program](building.md): turn the project into a single executable with `sn build`.

If you already have a Sonata project and a bot token, skip to [Your first bot](first-bot.md).
